CARA MENJALANKAN SIMULASI (1 MASTER + 9 WORKER)
================================================

0. CEK IP MASTER (laptop yang jadi Master)
   ipconfig
   Gunakan IPv4 pada bagian "Wireless LAN adapter Wi-Fi".
   Contoh: 10.113.0.148  --> GANTI DENGAN IP WIFI MASTER DI LAB.
   Jangan pakai 192.168.56.x (VirtualBox) atau 169.254.x.x (DHCP gagal).


1. DI PC MASTER (jalankan duluan)

   cd /d D:\Downloads\UAS_KPT\Distributed_Simulation
   py master\master.py --host 0.0.0.0 --port 5000 --iterations 100000 --chunk-size 5000 --output results\simulation_result.json

   Keterangan:
   - --host 0.0.0.0  = Master mendengarkan semua IP
   - --min-workers 9 = SUDAH DEFAULT, tidak perlu ditulis
   - Master baru mulai setelah 9 worker terdaftar (maks. tunggu 15 menit)

2. DI 9 PC WORKER (jalankan setelah Master aktif)

   PC Worker 1:
   cd /d D:\Downloads\UAS_KPT\Distributed_Simulation
   py worker\worker.py --host 10.113.0.148 --port 5000 --id WORKER-01 --processes 4

   PC Worker 2:
   py worker\worker.py --host 10.113.0.148 --port 5000 --id WORKER-02 --processes 4

   PC Worker 3:

   PC Worker 4:

   PC Worker 5:

   PC Worker 6:

   Ganti 10.113.0.148 dengan IP WiFi Master yang sebenarnya di lab.


3. CATATAN PENTING

   - --host pada worker = IP MASTER, BUKAN IP worker itu sendiri.
   - Tiap worker punya IP berbeda, tapi tidak perlu ditulis di perintah.
   - Yang dibedakan hanya --id: WORKER-01 s.d. WORKER-09.
   - --processes 4 = jumlah core yang dipakai tiap worker (sesuaikan PC lab).
   - Cek koneksi dari worker: ping <IP-WIFI-MASTER>
   - Firewall PC Master harus mengizinkan TCP port 5000.
   - Semua PC harus satu WiFi yang sama dan saling bisa ping.
   - Folder Distributed_Simulation harus ada di tiap PC worker.
   - Master nyalakan duluan. Worker yang start lebih awal akan gagal connect.
   - Hasil akhir: results\simulation_result.json


4. PENGUJIAN FAULT TOLERANCE (1 worker dimatikan saat simulasi jalan)
   ------------------------------------------------------------------
   Gunakan PowerShell di PC Master karena Tee-Object hanya ada di PowerShell.

   a. DI PC MASTER:

      cd D:\Downloads\UAS_KPT\Distributed_Simulation
      py master\master.py --host 0.0.0.0 --port 5000 --iterations 500000 --chunk-size 25000 --output results\fault_tolerance_result.json 2>&1 | Tee-Object -FilePath results\log-master-fault.txt

   b. DI 9 PC WORKER: jalankan ke-9 perintah seperti bagian (2) di atas.
      Pastikan ID unik WORKER-01 s.d. WORKER-09 (jangan ada ID dobel).

   c. Tunggu sampai Master menampilkan:

      Target worker tercapai! (9 worker terhubung)
      Memulai distribusi task simulasi...
      Task TASK-0001 (25000 iterasi) dikirim ke WORKER-01

   d. BARU setelah itu tekan Ctrl+C di terminal WORKER-01.
      Jangan matikan worker sebelum baris "Task ... dikirim ke ..." muncul.

   e. Yang harus muncul di Master:

      Worker WORKER-01 (...) terputus.
      [FAULT TOLERANCE] Mendeteksi task terbengkalai TASK-0001 ...
      [FAULT TOLERANCE] Task TASK-0001 berhasil dikembalikan ke antrean PENDING ...
      [RECOVERY] Task TASK-0001 siap ditugaskan kembali dari worker WORKER-01
      Task TASK-0001 (25000 iterasi) dikirim ke WORKER-07
      [PROGRES] Selesai: 20/20 (100.0%)
      Total Pemulihan Task       : 1

   f. Bukti tersimpan di:

      results\log-master-fault.txt
      results\fault_tolerance_result.json

   g. Catatan: Recovery Time tercatat 0.000 s karena deteksi dan requeue
      terjadi di detik yang sama. Untuk laporan: Recovery Time < 1 detik.

   ---------------------------------------------------------------
   HITUNG SPEEDUP & EFFICIENCY
   ---------------------------------------------------------------
   Jalankan di PowerShell setelah kelima JSON tersedia:

      $t1 = (Get-Content results\scalability_physical_1.json -Raw | ConvertFrom-Json).wall_clock_time

      foreach ($n in @(1,2,4,6,9)) {
        $d = Get-Content "results\scalability_physical_$n.json" -Raw | ConvertFrom-Json
        $sp = [math]::Round($t1 / $d.wall_clock_time, 3)
        $eff = [math]::Round(($sp / $n) * 100, 1)
        [pscustomobject]@{
          Workers = $n
          WallClock_s = [math]::Round($d.wall_clock_time, 4)
          Throughput = [math]::Round($d.throughput_iterations_per_sec, 0)
          Speedup = $sp
          Efficiency = "$eff%"
        }
      } | Format-Table -AutoSize

   Rumus:
      Speedup    = Waktu N=1 / Waktu N
      Efficiency = Speedup / N x 100%

   Bukti tersimpan:
      results\scalability_physical_1.json ... _9.json
      results\log-scalability-1.txt ... -9.txt

   ---------------------------------------------------------------
   CATATAN SCALABILITY
   ---------------------------------------------------------------
   - --min-workers harus ditulis eksplisit untuk N=1/2/4/6. Default Master = 9.
   - Jumlah worker aktif harus TEPAT sesuai N. Kalau lebih, hasil tidak valid.
   - --processes 4 bukan 4 worker; itu 1 worker dengan 4 child process.
   - Jangan matikan worker sebelum [PROGRES] 20/20 muncul.
   - Jika ada putaran timeout, ulang putaran itu dari awal.
